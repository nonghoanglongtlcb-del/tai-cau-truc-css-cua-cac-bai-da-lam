# Landing page Trà Tân Cương (SASS)

Bài tập tái cấu trúc CSS bằng SASS: variables, nesting, mixin, @each, @use.

## Chạy dự án
```
npm install
npm run build   # biên dịch một lần
npm run sass    # tự biên dịch khi sửa file scss
```
Mở `index.html` để xem.

## Cấu trúc scss/
`_variables` (màu, font, breakpoint) · `_mixins` · `_base` · `_navigation` · `_header` · `_featured` · `_statistics` · `_footer` · `style.scss` (gộp bằng @use)
